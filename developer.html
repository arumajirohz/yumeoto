Open-source software project

YUMEOTO

A browser-native Web Audio synthesis engine and developer playground. YUMEOTO demonstrates procedural signal generation, AudioNode graphs, filters, gain staging, LFO modulation, and a zero-dependency vanilla JavaScript architecture.

Web Audio API
Uses AudioContext, AudioBufferSourceNode, GainNode, and BiquadFilterNode.
Procedural DSP
Generates noise in real time instead of depending on bundled audio assets.
Audio Graphs
Connects generated sources through filters, gains, and modulation stages.
Zero Dependencies
Pure HTML, CSS, and JavaScript with no build step or runtime libraries.

Architecture

Noise Buffer
    ↓
BiquadFilterNode — tone shaping
    ↓
LFO → GainNode — modulation
    ↓
Master Gain — output control
    ↓
AudioContext.destination

Example

const ctx = new AudioContext();
const osc = ctx.createOscillator();
const gain = ctx.createGain();

osc.connect(gain).connect(ctx.destination);
osc.start();
